# YouthX Research website

Source for [youthx.vercel.app](https://youthx.vercel.app). Built with Astro and deployed on Vercel.

```sh
npm install
npm run dev     # local server
npm run build   # type check + build
```

Posts live in `src/content/posts/` as MDX files. The home page lists projects and news in `src/pages/index.astro`.
